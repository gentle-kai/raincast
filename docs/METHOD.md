# 方法与局限

**简体中文** | [English](METHOD.en.md) · [README](../README.md)

## 背景与残差

共享 U-Net 接收 12 个数据通道和 3 个模态可用性通道。回归输出为 NWP 的 log1p 雨量加上受 tanh 约束的修正。±0.35 是 log1p 空间的范围，不是固定毫米修正，也不是动力方程约束。回归头零初始化，初始输出等于背景。

## 分类与损失

示例使用 0.1、5、20、50 mm 四个强度分界，得到五个左闭右开等级。三个输出时段的实际时间由数据提供者定义。这些边界只是演示配置，修改时需同时调整标签、损失和文档。

联合损失为 `0.30 * SmoothL1 + focal CE + 0.75 * Soft-TS`。focal 指数为 2，等级权重为 0.15/1/5/25/100；Soft-TS 对存在真实事件的时段和等级取平均。它是训练代理目标，不提供综合评价分数。

回归和分类是不同输出，两者不保证逐点一致。回归转成毫米后需要裁剪为非负。

## 采样与缺失

训练可优先采样含强降水的 patch，验证默认居中裁剪。真实任务应另外进行全网格评价。随机模态丢弃不会自动发现缺失文件；推理调用者必须显式处理输入及可用性通道。

## 可复现范围

随机合成数据只验证软件流程。没有真实气象数据的精度、泛化或业务效果结论。训练使用非确定性后端，裁剪随机生成器没有绑定全局 seed，因此不承诺逐位一致。

建议在真实任务中设置同预算 NWP 基线，再分别验证有界残差、多任务和模态丢弃的增量收益。按天气过程留出评估集，并报告逐时段、逐强度结果及不确定性。
