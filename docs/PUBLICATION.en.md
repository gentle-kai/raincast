# Use and Distribution

[简体中文](PUBLICATION.md) | **English** · [README](../README.en.md)

This directory is a standalone, general-purpose method demonstration. It contains source code, documentation, and a program for generating random synthetic data. Ignore rules exclude data caches, generated weights, personal configuration, and runtime logs from Git tracking.

The project is licensed under the MIT License. See the [LICENSE](../LICENSE) file in the repository root for the full terms.

Use only data you are authorized to use and distribute. Generated demonstration data does not represent real weather and cannot substantiate claims about forecasting performance.
